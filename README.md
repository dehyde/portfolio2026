# Tom Bar-Gal — portfolio

This repository contains the current portfolio prototype: a case study about custom data management across Autodesk Construction Cloud account and project levels.

## Contents

- `index.html` — the interactive case-study prototype
- `assets/` — persona and case-study imagery
- `js/` — navigation, sidecar, and annotation behavior
- `docs/copy-style.md` — editorial guidance for future case-study writing
- `tests/` — focused behavior and design-system checks
- `archive/legacy-portfolio/` — the previous portfolio site, retained intact

## Preview

Serve this directory with any static web server, then open `index.html`.

## Checks

Run the focused checks with:

```sh
node --test tests/*.test.mjs
```
